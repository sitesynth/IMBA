# Гайд по скриншотам для статей блога

## Зачем это нужно (коротко)
1. **E-E-A-T:** скриншоты — единственное доказательство «проверено на реальных устройствах». Google ранжирует инструкции с реальными скриншотами выше генерик-текстов, LLM охотнее цитируют.
2. **Уникальность:** текст можно переписать, скриншоты вашего кабинета — нет. Это защита от копирования и фактор в Google Images (доп. источник трафика).
3. **Конверсия:** пользователь сверяет свой экран со скриншотом на каждом шаге — меньше бросают на середине, меньше обращений в поддержку.

## Общие правила
- Реальные интерфейсы, никаких стоков и монтажа
- **Замазать ссылку подписки** (это доступ к аккаунту) и любые личные данные
- Формат PNG или WebP, ширина 1200–1400px, сжать перед загрузкой (tinypng)
- Имена файлов с ключами: `vpn-windows-happ-podpiska.png`, не `IMG_0231.png`
- Каждому скрину alt-текст: «Добавление подписки IMBA в Happ на Windows»
- Тёмная тема Happ/кабинета — совпадает со стилем блога, выглядит нативно

## Какие скрины и куда

### Статья 1: VPN на компьютер (/blog/vpn-na-kompyutere) — 4 скрина
1. Кабинет IMBA: блок «Happ — ссылка подписки» с кнопкой «Копировать» → в Шаг 2
2. Happ на Windows: экран «+» → «Добавить подписку» → в Шаг 4
3. Happ: настройки сервера с выключенным Mux (подсветить тумблер) → в Шаг 5 — **самый важный скрин**: главная точка отказа пользователей
4. Happ: статус «Подключено» с выбранным сервером → в Шаг 5, финал

### Статья 2: VPN на Android (/blog/vpn-android) — 5 скринов
1. Кабинет: кнопки APK Stable / Beta / Зеркало → в Шаг 2
2. Android: системный диалог «разрешить установку из неизвестных источников» → в Шаг 2 — снимает страх «это безопасно?»
3. Happ: добавление подписки → в Шаг 3
4. Happ: Mux выключен → в Шаг 4
5. Android: системный запрос на VPN-подключение → в Шаг 4

### Статья 3: VPN на iPhone (/blog/vpn-iphone) — 5 скринов
1. Кабинет: кнопки App Store / TestFlight → в Шаг 2
2. TestFlight: экран установки Happ → в Шаг 2 — ключевой для тех, у кого Happ не находится в App Store
3. Happ: добавление подписки → в Шаг 3
4. Happ: Mux выключен → в Шаг 4
5. iOS: запрос «Разрешить добавление конфигурации VPN» + значок VPN в статус-баре → в Шаг 4

### Статья 4: VPN на телевизоре (/blog/vpn-smart-tv) — 5 скринов (фото экрана ТВ допустимы)
1. Downloader с введённой ссылкой на APK → в Шаг 2, вариант А
2. Установка APK на Android TV → в Шаг 2
3. Добавление подписки на ТВ (QR или ручной ввод — по фактическому флоу) → в Шаг 3
4. Happ на TV: Mux выключен → в Шаг 4
5. Финал-доказательство: YouTube открыт на телевизоре, видео в 4K → в Шаг 4 — эмоциональная точка «оно работает», можно фото экрана

## Приоритет съёмки
Если делать по очереди: сначала статья 1 (компьютер — самый большой ключ), в ней скрин 3 (Mux) — важнее всех остальных вместе взятых. Скрин кабинета с «Happ — ссылка подписки» переиспользуется во всех четырёх статьях — снять один раз.

Итого: 19 скринов, из них 1 переиспользуемый → 16 уникальных съёмок.
